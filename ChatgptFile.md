## Running locally

Use the project root as the working directory:

    npm ci
    npm start

Browser view: npm run dev (default port 5173). Native window buttons act only in Electron.

Checks:

    npm run check
    npm test

Windows build:

    npm run release:windows

Requires NSIS 3.11+ available as makensis, or an explicit MAKENSIS path. See WINDOWS-BUILD.md. The cloud build had a locally extracted compiler at /workspace/.tools/nsis; that path and its dependencies are not portable to a Windows PC. Install NSIS locally and supply its real compiler path. npm dependencies are pinned in package-lock.json.

If Electron downloads require a corporate/cloud proxy, use the environment's supported proxy and CA configuration. Do not disable TLS/checksum verification. Do not copy cloud credentials or proxy values into the local project.

- Hidden backing directory: .executables/ containing the runtime, three executable counterparts, icon and release.json.

- Desktop shortcuts: PLASMATIO Folder, PLASMATIO App, PLASMATIO Installer.
- Successful installer removes known older PLASMATIO shortcut names, opens the installed three-item directory and launches the app.
- Portable shortcuts cannot run from inside a ZIP. Relative shortcut icons/working directories are less dependable than installed absolute shortcuts.
- Preferred entry point for a Windows user is the standalone installer copied from releases/windows/.executables/Setup.exe.

Generated runtime trees are ignored by Git; installers/ preserves the current standalone Windows installer and checksum for direct GitHub downloads. Never delete arbitrary desktop shortcuts, installed user files, or Folder content when cleaning generated artifacts.
